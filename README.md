# SGSI Banco Meridian

Proyecto académico de diseño e implementación de un Sistema de Gestión de Seguridad de la Información para Banco Meridian, S. A. (escenario ficticio).

## Alcance
- P01: Consulta de saldos de cuentas autorizadas.
- P02: Transferencias internas.
- Arquitectura objetivo: Microsoft Azure e infraestructura local.

## Estado inicial
El informe v.2 reporta ocho pruebas locales; su código y evidencias están pendientes de incorporación y verificación. Azure es una arquitectura objetivo, no un despliegue comprobado.
