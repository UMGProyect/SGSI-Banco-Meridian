# DevSecOps del laboratorio P01/P02
Código base validado en la ejecución EV-GCP-11, sin modificaciones de los dos archivos Python. Los resultados no son afirmaciones de ausencia universal de vulnerabilidades.
La primera SCA utiliza solo cryptography 41.0.7 (versión upstream observada en VM). El archivo es inventario, no instrucciones de instalación. Ubuntu puede aplicar backports; contrastar hallazgos con versión dpkg y USN. Pendiente inventario del core Windows y dependencias transitivas, Python, OpenSSL, SQLite y sistema operativo; no tratarlos como cubiertos por esta ejecución. DAST pendiente: utilizar exclusivamente API de laboratorio y túnel, con datos sintéticos; no exponer la VM públicamente. No cambiar el código probado ni marcar riesgos como mitigados sin repetir pruebas.
